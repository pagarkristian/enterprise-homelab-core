## 🛡️ 4. Recommendations

**TODO — write these in your own words.** For each finding, what is the actual fix (not just "add detection" — detection is not remediation)? For example:
- IDOR → check that the logged-in user's session matches the record being requested, not just that *a* session exists.
- SQLi → use prepared statements, same as `index.php` already does.
- Upload → validate file content (not just extension), store uploads outside the web root or with randomized non-executable names, disable directory listing.
- Command injection → never pass user input to `shell_exec()`; if resizing is needed, use a PHP image library (e.g. GD or Imagick's PHP bindings) instead of shelling out.
